# Adityagthe1-code's Arcade

A small personal game arcade hosted at [adityagthe1-code.github.io](https://adityagthe1-code.github.io).

## Customize the homepage

- Edit the one-line bio in `index.html` near the `welcome-copy` section.
- Replace `assets/nothing-but-net-cover.svg` to change the featured game's poster.
- The basketball game lives in `games/nothing-but-net/index.html`.

## Publishing

GitHub Pages is configured to publish the repository root with the GitHub Actions workflow at `.github/workflows/pages.yml`. Push changes to `main` to deploy them.
